## 核心盟约

### 巴别塔

在场3名巴别塔干员时

**【巴别塔】干员攻击力、生命值提升（受层数影响）；每有一名【巴别塔】干员所属的其它盟约种类与已计入的不同，全体【巴别塔】干员额外获得攻击力提升（最高+20%）**

| 项     | 数值                                                         |
| ------ | ------------------------------------------------------------ |
| 主效果 | 全体【巴别塔】干员攻击力、最大生命值 ×`(1 + 0.12 + 0.008·L)`（**双属性**） |
| 副效果 | 成员携带的**其它盟约种类**每有 1 种不同，全体成员 ATK **+4%**，**上限 +20%**（即 5 种封顶，为独立加成，最终乘算，只作用于 ATK） |

在场6名巴别塔干员时

 **战斗开始时，攻击力最高的【巴别塔】干员成为【指挥】。【指挥】及其周围八格内的友方干员造成的伤害提升至 120%，攻击时无视 20% 的防御力和法术抗性。【指挥】被击倒时，【指挥】移交给场上攻击力最高的下一名【巴别塔】干员。**

| 项     | 数值                                                         |
| ------ | ------------------------------------------------------------ |
| 主效果 | 【指挥】及其周围八格内的友方干员造成的伤害提升至 120%（受层数影响） |
| 副效果 | 攻击时无视 20% 的防御力和法术抗性（受层数影响） |

## 附加盟约

### 元素

在场2名【元素】干员时（游戏内文案：「（受层数影响）」；机制上 L 封顶 150）：

【元素】干员造成的**元素损伤** ×`(1 + 0.1 + 0.003·L)`，L = min(L, 150)

也就是【元素】干员造成的**元素损伤**提升55%（150 层时）



在场3名【元素】干员时（游戏内文案：「（受层数影响）」；机制上 L 封顶 200）：

凋亡损伤爆发：此次元素爆发造成的伤害提升至（110-325）%；目标攻击力额外最终降低至70%

灼燃损伤爆发：此次元素爆发造成的伤害提升至（195-494）%；法术抗性额外-20

神经损伤爆发：此次元素爆发直接造成的伤害提升至（110-260）%；冷却期间每秒额外受到（500-1300）点无来源的元素持续伤害

侵蚀损伤爆发：防御力额外永久-120；冷却期间每0.03秒受到额外一次、共十次、每次(750-1950)点的无来源物理持续伤害
